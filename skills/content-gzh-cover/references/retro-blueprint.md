# 复古图纸聚焦风

按主 Skill 的横图优先与同图左侧 1:1 裁切规则构图；字号由整张横图决定，文字少时保持合理留白。

地面是整片连贯的米白暖灰羊皮纸色，可带极轻微纸张颗粒与自然褪色，以及少量极淡的青绿写意树影；不做明显脏污、破损或大面积划痕。

远景是一层淡墨写意式的轮廓，内容从本篇正文提取——城市题材取天际线起伏与可识别地标剪影，其他题材取该文场景的大致轮廓；轮廓松弛、有手绘或水墨的透气感，不细画每一个细节。

前景锚定一个等距视角（isometric）的主体，同样从正文提取：可以是一件器物、一组结构、一处空间或一套系统关系，轮廓清晰、结构明确，是画面里最「实」、最聚焦的部分。

用细线框做「定位框」：主体被一个或多个嵌套的细矩形线框框住，线框内层再框住主体的核心部分，形成一层套一层的聚焦结构；画面边缘可有细边框、裁切标记、十字定位线或引线注释。定位框始终框住本文的核心主体，表达「聚焦到这一点」，不是装饰。线框细、轻、克制，不抢主体，不画成复杂工程图。

层次：淡墨远景 → 暖纸地面 → 实的等距主体 → 最上层的细线框与文字。配色控制在米白、暖灰、灰棕、深墨灰、少量低饱和青绿或蓝灰之间，可加极小一点金或铜点缀，整体偏暖、偏旧、安静。复古感来自纸张质感、淡墨远景和细线框语言，不用做黄、做脏、低清晰度或严重褪色来堆砌。

文字为克制的复古档案式排版：主标题 1 处、副标题最多 1 处，可带一条极小的顿点分隔关键词行（内容必须来自正文）；不得自行编造城市名、坐标、年份、价格、口号或品牌信息。

不要单一主体纯色海报、大片空白居中或低机位仰视的公式构图；不要明亮高饱和色块、荧光霓虹或强对比丝网印刷；不要照片写实、密集细节、玻璃反射、金属反光或 CGI 效果图；不要复杂工程蓝图——密布尺寸标注、剖切线、爆炸图、数据图表或信息图布局。目标约 2.35:1。
